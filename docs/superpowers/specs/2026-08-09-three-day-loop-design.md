# 海风球场三日生活循环设计

## 目标

把现有的单日垂直切片扩展为一个可连续游玩、可保存、会产生长期变化的三日生活循环。玩家应当在 25-35 分钟内体验春 12 至春 14，并明确感受到场地、人际关系、库存和经营结果会延续到第二天。

完成后，原型应当从“完整一天的交互演示”推进为“具有生活模拟骨架的游戏切片”。

## 设计原则

- 保持低压力。没有失败倒计时、债务、饥饿、疾病恶化或永久错过剧情。
- 选择产生差异，但不制造惩罚。训练、交谈和修缮均可以延后。
- 每天保留熟悉的节奏，同时至少有一处新变化。
- 场地变化必须在地图上持续可见。
- 关系内容影响对话和结尾，不阻断经营主循环。
- 继续使用现有海边球场，不在本阶段扩展第二张地图。

## 本阶段范围

### 包含

- 春 12、春 13、春 14 三个连续日期
- 浏览器本地存档、继续游戏和重新开始
- 每日变化的天气、目标、订单与人物对话
- 跨日保留的钱、库存、修缮、关系和事件记录
- 一次可重复的简短射门训练
- 三日结束时的第一个剧情节点
- 桌面键盘、鼠标、手机触控完整支持

### 不包含

- 新地图、室内场景和地图切换
- 四季、完整月历和长期赛季
- 正式足球比赛或球队经营模拟
- 角色恋爱、礼物系统和复杂好感度树
- 云存档、账号和服务器
- 背包容量、装备、技能树和制作树

## 玩家体验

### 春 12：抵达

沿用当前流程：自由探索、收集小店备料、可选地与郭教练交谈、下午经营小店、傍晚完成第一处修缮。

这一天建立人物误会与场地状态。日结后，修好的设施仍留在地图上，剩余零钱与物品进入第二天。

### 春 13：一起训练

天气转为海风较强。上午郭教练开放一次射门训练。玩家可以参加训练，也可以直接收集备料和开店。

参加训练消耗少量体力并提高郭教练信任。射门成绩只影响对话措辞，不影响当天是否能够开店。下午订单与春 12 不同，傍晚可以修第二处设施，也可以保留零钱。

### 春 14：友谊赛日

球场迎来周末友谊赛，背景仍使用当前地图，但通过更多场边人物、目标文案和订单数量表现客流变化。上午仍可进行训练或备料。

下午有五位客人。当天结束后触发第一个剧情节点：郭教练不再把安若童视为来裁撤球队的人，而是正式询问她是否愿意继续留下。对话会根据训练参与和修缮数量产生不同措辞，但三条结果都进入同一个可继续状态。

## 每日循环

每一天按以下阶段推进：

1. 上午自由活动：走动、采集、对话、训练或休息。
2. 下午场边小店：根据当天订单服务客人。
3. 傍晚场地安排：购买一处尚未完成的修缮，或保留零钱。
4. 夜晚结算：查看当天变化，保存并进入下一天。

进入下一天时：

- 体力恢复到 100。
- 水补充到至少 4 份，布补充 1 份但上限为 3。
- 四个采集点重新出现。
- 钱和未使用物品保留。
- 已完成修缮、关系和剧情标记保留。
- 安若童从球场入口开始新的一天。

## 每日内容配置

每日差异由数据配置提供，不把日期分支散落在界面代码中。

### 春 12

- 天气：海风转晴
- 订单：青草茶、干净毛巾、果子水、青草茶
- 训练：不可用
- 日终主题：第一次留下变化

### 春 13

- 天气：风大有云
- 订单：果子水、青草茶、干净毛巾、果子水
- 训练：可用
- 日终主题：第一次参与球队日常

### 春 14

- 天气：晴，午后海风
- 订单：青草茶、果子水、干净毛巾、果子水、青草茶
- 训练：可用
- 日终主题：友谊赛后的留下邀请

## 射门训练

训练是一个 20-30 秒的可选小游戏，每天最多完成一次。

### 操作

- 与郭教练互动后选择“练三脚”。
- 球门上依次出现三个目标区。
- 力量指针在横条内往返移动。
- 桌面按空格或 E，手机点击“射门”。
- 指针落在目标中心得 2 分，落在边缘得 1 分，其他位置得 0 分。

### 结果

- 总分 0-2：郭教练给出轻松的基础建议。
- 总分 3-4：郭教练信任增加 1。
- 总分 5-6：郭教练信任增加 1，并增加一条特殊记录。
- 所有成绩都允许继续当天流程。
- 训练消耗 8 点体力，但体力不会阻止开店或结束当天。

### 表现

训练使用地图内球门目标、球和一条简洁力量计，不打开独立网页式大面板。动画只使用位移和透明度，并支持减少动态效果。

## 状态模型

当前单日状态扩展为游戏状态：

```js
{
  version: 1,
  dayIndex: 0,
  phase: 'morning',
  minute: 550,
  energy: 100,
  money: 0,
  inventory: { tea: 0, fruit: 0, cloth: 2, water: 4 },
  collectedToday: [],
  ordersServed: 0,
  repairs: [],
  relationship: {
    coachMet: false,
    coachTrust: 0
  },
  training: {
    completedToday: false,
    lastScore: null
  },
  events: [],
  journal: [],
  history: []
}
```

`history` 只保存每天的日期、收入、修缮、训练分数和关键人物事件，不复制完整日志。

## 模块边界

### `daily-content.js`

提供三天的天气、订单、目标、对话和日终文案。它只包含数据，不读取浏览器状态。

### `game-state.js`

继续承载纯状态转换，扩展为：

- `createGameState()`
- `collectItem()`
- `talkToCoach()`
- `startTraining()`
- `finishTraining()`
- `openShop()`
- `serveOrder()`
- `buyRepair()`
- `chooseSaveMoney()`
- `finishDay()`
- `advanceDay()`

所有转换接收普通对象并返回新对象，不直接操作 DOM 或本地存储。

### `save-game.js`

负责序列化、校验、读取、写入和删除存档。存档键为 `seabreeze-club-save-v1`。

### `training-game.js`

负责三次射门的目标、指针和计分。计分逻辑可以独立测试，渲染通过回调把最终分数交给状态层。

### `game.js`

继续负责地图移动、交互分发、界面渲染和镜头。日期差异从 `daily-content.js` 读取，存档通过 `save-game.js` 完成，不在控制器中复制规则。

## 存档与恢复

- 每次成功采集、对话、训练、服务订单、修缮和推进日期后自动保存。
- 移动位置每 2 秒节流保存一次，刷新后可以回到接近原位置。
- 存档存在时，首次打开显示“继续游戏”和“重新开始”。
- “重新开始”需要第二次确认，避免误删。
- JSON 无法解析、版本不支持或关键字段缺失时，不覆盖坏存档。页面显示一条说明，并允许开始新游戏。
- 结算春 14 后仍保留存档，状态标记为 `chapterComplete`，玩家可以查看三日记录或重新开始。

## 界面变化

- 左上角日期从固定“春 12”改为状态驱动。
- 天气从固定文案改为每日配置。
- 今日记录增加三日历史页签，但默认仍显示当天，避免信息过载。
- 春 13 起，靠近郭教练时根据状态提供“交谈”或“练三脚”。
- 傍晚修缮界面增加“今天先存下”选项。
- 日结按钮在春 12、13 显示“睡一觉”，春 14 显示“查看这三天”。
- 首次加载的继续界面保持小型游戏标题卡，不做网页式欢迎页。

## 数据流

1. 页面启动时由 `save-game.js` 检查存档。
2. 玩家选择继续或新游戏后，`game.js` 获得游戏状态并渲染当天配置。
3. 玩家行为通过 `game-state.js` 产生新状态。
4. `game.js` 渲染新状态，并在成功转换后调用保存。
5. 训练由 `training-game.js` 运行，结束时只提交一个整数分数。
6. 日结先写入 `history`，再推进日期并重置当日字段。

## 异常处理

- 非法阶段操作只新增一条温和提示，不改变资源。
- 订单材料不足时保留当前客人，不扣库存。
- 已完成的修缮不再显示为可购买。
- 三处修缮全部完成后，傍晚只显示保留零钱和结束当天。
- 训练中离开页面时不记录成绩，恢复后可以重新开始。
- 手机浏览器失去焦点时清除按键与训练指针状态。

## 测试

### 纯状态测试

- 三天可以从春 12 推进到章节完成。
- 钱、库存、修缮和关系正确跨日保留。
- 当日采集点、体力和订单计数正确重置。
- 每日订单顺序不同且价格正确。
- 训练一天只能完成一次，分数正确影响信任。
- 选择保留零钱可以结束傍晚阶段。
- 已修缮设施不能再次购买。
- 春 14 结算生成章节完成状态和三条历史记录。

### 存档测试

- 有效状态可以保存并无损恢复。
- 坏 JSON、错误版本和缺失字段被安全拒绝。
- 删除存档只删除项目自己的键。

### 浏览器测试

- 完成三日主路径并到达章节结尾。
- 完成一次训练路径，并验证分数和关系变化。
- 中途刷新后继续游戏，日期、阶段和修缮仍存在。
- 1440x900 与 390x844 无横向溢出。
- 手机可完成移动、互动、训练、开店、修缮和日结。
- 控制台没有运行时异常或错误日志。

## 验收标准

- 玩家可以连续完成三个不同日期，不需要刷新页面。
- 刷新页面后可以继续当前日期和阶段。
- 至少一处修缮在第二天地图上持续可见。
- 春 13 或春 14 可以完成一次三脚射门训练。
- 三天的天气、订单和主要目标均不同。
- 春 14 日结出现基于关系与修缮结果的留下邀请。
- 所有既有单日核心流程仍然可用。
- 单元测试、存档测试和完整浏览器测试全部通过。
