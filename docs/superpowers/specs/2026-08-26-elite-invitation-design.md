# 精英邀请赛设计

## 1. 目标

海风联赛已经能根据最终排名和球场建设判定精英资格，但资格目前只是一句结算文字。这个里程碑把资格变成真正可玩的赛季终章：玩家收到邀请、选择赛前准备、完成三个比赛时刻，并把胜负与奖励永久留在后续赛季。

这一段不扩展成另一套多轮联赛。它是一场紧凑的高潮赛，用此前一整个赛季的排名、建设和玩家当下选择共同决定结果。

## 2. 进入条件与分支

- 资格规则保持不变：联赛最终排名前四，并且五项建设总等级至少六级。
- 达标后，第七轮结算生成一封当届精英邀请，主按钮改为“接受精英邀请”。
- 未达标时继续显示下一赛季入口，关系、建设和事件记录照常保留。
- 玩家打开邀请后仍可选择“本届不参加，进入下一赛季”。放弃只影响当届邀请，不清除建设、关系或历史成绩。
- 精英赛进行中不能直接开始下一赛季。完成比赛以后才能继续。

## 3. 对手与赛前准备

对手是来自省级青训体系的“鹤岭青训联队”。他们代表更成熟的资源与组织方式，不被写成恶意反派。

玩家只能选择一种准备路线：

1. **六个人共写比赛计划**：让教练、队长、年轻球员、小店、投资方和评审把分歧写在同一张纸上，对应“共同计划”回调。
2. **留出临场维修预案**：先把入口、灯光与急救点重新走一遍，对应“维修预案”回调。
3. **照常开放社区时段**：不因精英队到访就取消原有预约，对应“开放球场”回调。

准备不消耗联赛行动，不立即扣钱或重复增加属性。它只决定第三个比赛时刻中哪种处理方式真正准备过，避免刷新页面或中断比赛时重复结算收益。

## 4. 三个比赛时刻

比赛以海风队 0 比 2 落后开场。三个时刻都使用普通经营语言，不要求玩家理解足球术语。

### 时刻一：第一脚怎么交出去

- “照联赛里练过的次序出球”由前四名资格回调，成功时海风队进一球。
- 另外两项是可选立场，但不会自动得到此前赛季的帮助。

### 时刻二：看台入口临时复检

- “打开已经修好的分流通道”由六级建设回调，成功时避免对手利用混乱再扩大优势，客队进球减一。
- 另外两项可以完成场面，但不会获得建设回调。

### 时刻三：最后十分钟由谁拍板

- 三个选项分别对应共同计划、维修预案与开放球场。
- 只有与赛前准备一致的选项获得回调并为海风队再进一球。

三次都选中真实准备时，海风队以 2 比 1 获胜；漏掉一次通常战平；漏掉两次或更多会失利。结果来自此前经营与现场选择的组合，而不是随机数。

## 5. 永久结果

精英赛完成后记录：赛季编号、准备路线、三个选择、比分和结果等级。

- **击败精英队**：奖金 160 元，凝聚 +4，社区 +8。
- **让精英队记住海风**：平局奖金 90 元，凝聚 +2，社区 +4。
- **第一次精英赛结束**：失利补贴 50 元，凝聚 +1，社区 +2。

历史记录永久保留，并维护最佳结果。下一赛季重置积分榜和新的精英资格，但不会清除精英赛历史。

## 6. 状态与兼容

`season.elite` 使用独立纯状态：

```js
{
  status: 'idle' | 'invited' | 'match' | 'complete',
  invitedSeasonNumber: null | number,
  preparationId: null | string,
  match: null | {
    momentIndex: number,
    homeGoals: number,
    awayGoals: number,
    choices: string[],
    callbackIds: string[],
    complete: boolean,
    snapshot: object
  },
  result: null | object,
  history: object[],
  bestResultId: null | 'attended' | 'recognized' | 'champion'
}
```

版本号保持 5。缺少 `elite` 字段的旧存档在加载与克隆时补成空状态。浏览器在精英赛中断时回到“已邀请”状态，不保留半场选择，也不会重复发奖励。

## 7. 界面

新增一张精英邀请赛对话层，沿用现有海风球场的浅蓝纸张、珊瑚色实体按钮与手绘人物语言：

- 邀请状态显示对手、资格来源和三种准备路线。
- 比赛状态显示比分、当前时刻、三项选择以及哪些过去成果会回应。
- 完成状态显示永久结果、奖励与“进入下一赛季”。
- 手机宽度改为单列，主按钮不换行，弹层不产生横向溢出。

## 8. 验证标准

- 未达资格的赛季不能创建或开始精英赛，并能正常进入下一赛季。
- 达标赛季只生成一次邀请。
- 三种准备路线都能开始比赛，只有匹配路线在第三个时刻触发。
- 全部正确、漏一次和漏两次分别覆盖胜、平、负。
- 奖励只结算一次，精英历史和最佳结果跨赛季保留。
- 旧版本 5 存档正常加载；中断的精英赛安全回到邀请状态。
- 完整浏览器流程覆盖达标赛季结算、移动端邀请界面、三次选择、永久结果与下一赛季。
