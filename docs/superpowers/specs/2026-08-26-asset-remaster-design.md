# 海风球场素材分批升级设计

## 目标

保留现有可玩内容和两张手绘地图，分批替换最像临时 Demo、最破坏画风统一的素材。玩家首先应记住海边球场本身，其次才是界面数值。所有新素材都使用清楚的墨线、赛璐璐式平涂阴影和克制的水粉纹理，不再混用高亮像素风与泛水彩插画。

## 视觉方向

- 场景类型：面向泛玩家的海边社区足球场经营养成游戏。
- 美术语言：1990 年代日式电视动画背景道具，清晰轮廓、平涂阴影、手工磨损和海盐痕迹。
- 色彩：海蓝、旧青绿、珊瑚红、暖米白、蜂蜜木色与旧黄铜。
- 文字原则：生成素材不包含中文。招牌和冠名文字由 HTML 排版，保证三条剧情路线的名字准确切换。
- 接入原则：采用版本化文件名，不覆盖旧素材；每批都通过桌面、窄屏和完整剧情流程后再进入下一批。

## 批次

### 第一批：身份锚点与高频道具

已完成：

- `stadium-sign-frame-v2.png`：旧青绿木框、珊瑚红名牌、灯塔与足球徽章。
- `stadium-sponsor-cloth-v2.png`：带绳结、缝边、海风褶皱的空白蓝布。
- `item-atlas-handpainted-v2.png`：茶草、果筐、毛巾、青草茶、果子水、零钱袋、球网、篷布、木料与锤子。

招牌定位从画面几何中心移到主看台后方记分牌中心。旧招牌、覆盖状态和联合冠名仍使用原有剧情状态机。

### 第二批：球场本体

不重画整张地图，只制作能叠加和替换的场地素材：草坪磨损与补草、两套球门网、看台入口门楣、灯光塔灯罩、海风旗、边线水壶和替补席。重点增加比赛日层次，同时保持可行走区域清楚。

### 第三批：主线记忆物

把第一周和第二周的剧情道具统一到与地图相同的赛璐璐手绘语言。每件物品必须有独立轮廓和真实使用痕迹，不依靠长文字解释其身份。

### 第四批：经营生活小物

补齐场边小店货架、训练器材车、周末摊位、建设阶段材料与交互后的状态变化。高频物件优先，纯装饰物最后处理。

## 第一批生成提示摘要

1. 透明宽幅球场招牌框：空白中心、海边社区足球元素、旧青绿木框、珊瑚红内板、灯塔足球徽章、1990 年代日式电视动画背景道具、无文字。
2. 透明冠名蓝布：四角绳结、米白缝边、自然褶皱与盐风磨损、空白中心、同一动画道具语言、无文字。
3. 透明九格日常道具图集：固定三乘三坐标、统一三分之四视角与左上光源、清晰小尺寸轮廓、无格线、无文字、无像素风。

## 验收标准

- 招牌正对记分牌结构，桌面与 390 像素窄屏均不遮挡球场关键人物或入口。
- 覆盖蓝布能显示准确冠名文字，社区保名和联合冠名路线仍可切换。
- 九格道具保持原坐标映射，快捷栏、采集、修缮和点单画面不需要修改逻辑。
- 新素材使用透明通道，不出现黑底、白边、发光和像素化渲染。
- 完整浏览器流程和全部规则测试通过，控制台无错误。
