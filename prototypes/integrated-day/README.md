# 海风球场：安若童的三天

这是一个可直接游玩的低压力生活模拟垂直切片。安若童因病暂时离开原来的生活，来到家族留下的海边社区球场。这里的人起初以为她是来关掉场地的，而她先从打开场边小店、认识球队和修好一些旧设施开始。

## 三日章节

1. 春 12 日「抵达」：自由探索球场，准备四份订单，认识郭教练，并决定第一处修缮。
2. 春 13 日「一起训练」：风变大了。郭教练开放三脚射门，小店出现新的四人订单。
3. 春 14 日「友谊赛日」：接待五位客人，完成最后一次傍晚选择，看到第一章结尾。

钱、剩余库存、修缮、郭教练关系与每天的记录会跨日保留。体力、收集点、订单进度和训练次数每天重置。傍晚可以修一处尚未完成的设施，也可以选择「今天先存下」。

## 游玩

直接打开 [index.html](./index.html)。

- 桌面：使用 WASD 或方向键移动，按 E 互动，按 J 查看今日记录。
- 手机：使用方向按钮和 E 按钮。
- 可以点击场景地面、人物或物品。点击远处目标时，安若童会先走到附近再互动。
- 春 13 日与春 14 日可以找郭教练踢三脚。看准珊瑚色区域，按 E、空格或「射门」按钮。每脚最高 2 分。

游戏在有效行动和移动过程中自动存档。刷新后会出现「继续游戏」和「重新开始」。重新开始需要再点一次「确认重新开始」，并且只清除本游戏的存档。

## 视觉资产

- 主场景是现代滨海社区球场，包含海滨步道、玻璃混凝土俱乐部、太阳能看台与模块化小店。
- 场景、安若童和完整球队人物统一为原创手绘儿童动画风格。
- 安若童使用四方向 16 帧行走表；球队使用完整六人角色表，郭教练不会再被裁切。
- 修好的球网、遮雨棚和看台会持续显示在场景中。
- 春 13 日的风与春 14 日的暖光会让同一张地图产生轻微变化。

## 验证

全部纯规则测试：

```bash
node --test prototypes/integrated-day/*.test.mjs
```

完整三日浏览器流程：

```bash
node prototypes/integrated-day/smoke-test.mjs
```

浏览器测试会实际走完三天，验证远距离点击行走、两次修缮、存钱选择、6 分训练、刷新后继续、三日历史、地图和人物贴图、1440×900 与 390×844 布局，以及浏览器控制台错误。

## 当前章节边界

- 目前只有海风球场这一张可行走地图，以及春 12 日到春 14 日三个日期。
- 友谊赛是这轮剧情的背景事件，还没有做成完整比赛玩法。
- 暂时没有室内地图、季节轮换、长期经济、角色送礼或更多球队关系线。
- 原始三方向对比 Demo 保留在 `../day-loop/`。
