# 安若童的休息日：核心循环原型

这是一个隔离的玩法探索页面，不是正式游戏工程。它用三个可切换的小型 Demo 验证《星露谷物语》式生活模拟的核心应该落在哪里。

## 已选方向

「自由的一天」与「场边小店」已经合并为 [完整一天 Demo](../integrated-day/index.html)。原始选择器继续保留，用于回看三个方向之间的差异。

## 运行

在项目根目录执行：

```bash
python3 -m http.server 4173
```

然后访问：

```text
http://localhost:4173/prototypes/day-loop/
```

## 原型方向

- 自由的一天：WASD 移动，E 互动；采集、交谈、修复并回屋。
- 一起练习：从五位人物中选择三人共度时间。
- 场边小店：完成四份订单，再把当天收入用于场地修缮。

底部选择器支持数字键 1-3、左右方向键以及 R 键重玩。

## 边界

- 所有玩法状态只存在于当前浏览器页面，刷新即重置。
- 场景概念图为本项目生成的原创原型资产。
- 选择方向后，再决定正式技术栈、地图系统、存档结构与美术管线。

## 验证

```bash
node prototypes/day-loop/smoke-test.mjs
```

测试会在无界面浏览器中跑通三个玩法结局，并检查桌面、手机宽度和浏览器控制台。
