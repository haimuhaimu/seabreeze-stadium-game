# 海风球场

一个以现代海边社区球场为舞台的经营养成游戏原型。

安若童因病暂时离开原来的生活，来到家族留下的球场。两个完整剧情周之后，玩家会进入八支球队参加的海风联赛，一边维持现金、建设球场、经营人物关系，一边用每轮真正完成的准备影响比赛和最终名次。

## 直接试玩

双击根目录的 `index.html`，或打开：

`prototypes/integrated-day/index.html`

游戏不需要安装依赖，也不需要联网。桌面端使用 WASD 或方向键移动，E 互动，J 查看记录；手机端使用屏幕按钮。

## 当前内容

- 三天抵达序章：自由探索、经营场边小店、训练与场地修缮
- 七天主线《最后一个名额》
- 两张可行走地图：旧训练场与海风主赛场
- 三项主动玩法：陪小满传球、场边小店筹款、查找旧记录
- 周五资金冲突、沈峤旧球员证反转、三段式比赛与五把椅子听证
- 七轮单循环联赛、八队积分榜与可重复的新赛季
- 六名常驻 NPC、每轮三项经营行动和五条永久建设线
- 前四、六级建设、人物关系、现金与精英邀请赛目标
- 本地自动存档与版本 1 至版本 4 旧存档迁移
- 桌面端和移动端适配

更完整的玩法与验证说明见 [游戏说明](prototypes/integrated-day/README.md)。

## 测试

```bash
node --test prototypes/integrated-day/*.test.mjs
node prototypes/integrated-day/smoke-test.mjs
```

纯规则测试共 110 项。浏览器验收会从春 12 日走到春 28 日，再完成联赛第一轮，并检查桌面、手机、存档、NPC 关系、建设、积分和完整剧情路线。

## 当前阶段

这是一个包含完整两周主线和可重复七轮联赛的可玩版本。比赛仍采用三次关键决定，还没有做成实时足球操控；室内场景、转会、伤病和随机赛季事件也仍待扩展。
