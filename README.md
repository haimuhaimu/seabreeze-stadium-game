# 海风球场

一个以现代海边社区球场为舞台的经营养成游戏原型。

安若童因病暂时离开原来的生活，来到家族留下的球场。第一周《最后一个名额》围绕一张空白通知展开：玩家只能先答应三项请求中的两项，并在比赛结束后决定以后谁有资格替球场作决定。

## 直接试玩

双击根目录的 `index.html`，或打开：

`prototypes/integrated-day/index.html`

游戏不需要安装依赖，也不需要联网。桌面端使用 WASD 或方向键移动，E 互动，J 查看记录；手机端使用屏幕按钮。

## 当前内容

- 三天抵达序章：自由探索、经营场边小店、训练与场地修缮
- 七天主线《最后一个名额》
- 两张可行走地图：旧训练场与海风主赛场
- 三项主动玩法：陪小满传球、场边小店筹款、查找旧记录
- 周五资金冲突、沈峤旧球员证反转、三段式比赛与五把椅子听证
- 本地自动存档与旧存档迁移
- 桌面端和移动端适配

更完整的玩法与验证说明见 [游戏说明](prototypes/integrated-day/README.md)。

## 测试

```bash
node --test prototypes/integrated-day/*.test.mjs
node prototypes/integrated-day/smoke-test.mjs
```

游戏规则测试共 61 项，另含浏览器启动路径测试。浏览器验收会从春 12 日走到春 21 日，并检查桌面、手机、存档和完整剧情路线。

## 当前阶段

这是一个可完整游玩首周的垂直切片，后续季节、长期人物关系、更多外队和持续经营系统尚未实现。
